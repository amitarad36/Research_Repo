# Which history contributes the direction on return?

**Decision.** Carried Adam produces a pair of return predictions outside the fresh optimizer's learning-rate ray. The perpendicular component is completely accounted for by the intervening B batch. Within this fixture the earlier A versus C contrast lies along the fresh ray. This closes the constructed direction test and leaves useful recovery unestablished.

**Construction.** Reuse cycle 23's f_theta(x,z)=theta.x+(z-50)/2, frozen reference f_0, default z=50 and connected absolute discrepancy. All residuals are negative at the actual per-example evaluations, so the batch gradient is half the feature mean. A contains (2,2),(2,-2); C contains (-2,2),(-2,-2); B repeats (0,2). All histories use two steps per batch, reset weights at each batch, and the same optimizer parameters as cycle 23. Equal-budget controls replace the first batch with either rows (2,1),(2,-1) (different inputs, identical mean gradient) or (0,2),(0,-2) (neutral mean). Retain two first moments, two second moments and one logical counter per history. The cleared arm zeros the moments at counter four, and fresh Adam starts at zero. No task labels or identity-based selection. All arms enter the identical first return update at weights zero. No claims on the second return step.

**Checked calculation.** A return weight pair (s,t) gives outputs (2s+2t,2s-2t). Fresh and matched-counter cleared produce a vector along (-1,-1). Let f be the fresh vector and u be a history's post-update vector from zero. Allow the best possible nonnegative scalar a=max(0,<u,f>/||f||^2) using only the outputs. For A,B the optimal scalar is .75203625, and the Euclidean residual norm is .00018669735. An equal-length rescaling cannot do better. The neutral,B arm has the same residual norm. The signed half-difference, 2t, is -.00013201496 after A,B, C,B, alias,B and neutral,B. This signed component (projection onto the orthogonal line, up to normalization) avoids confusing the nearest point on a ray with projection onto its full span when the best scale is zero, as it is for C,B. A,B minus C,B is (-.00017469211,-.00017469211), exactly parallel to fresh by algebra. Only B excites coordinate two; its entire gradient history is equal on that coordinate in all four carried arms. Coordinatewise Adam makes their second-coordinate weights equal. A and the alias have identical gradients at both first-batch steps and hence identical states thereafter. Distinct input batches with the same gradients are indistinguishable here. These facts do not exclude older-task directional effects on other gradients or architectures.
