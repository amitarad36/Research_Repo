# What survives the batch weight reset

Result: in a two-coordinate connected IT3 surrogate, changing the first task reverses the first return prediction with the same current gradient, matched Adam step counters, and identical second-moment vectors. Pre-return predictions coincide. This is a constructed feasibility result about readaptation. It concerns the first step of a two-step return episode and has no evaluated performance endpoint.

**Graph and schedule.** Use f_theta(x,z)=theta.x+(z-50)/2 with fixed f_0, student default z=50, and L=|f_0(x,q)-q|. With q=theta.x, r=-25-q/2 stays negative in all verified calls. The reference-input derivative is 1/2, so the ordinary student loss gradient is x/2. Each task batch may be viewed as two identical copies giving the same mean gradient. Inputs A=(2,0), C=(-2,0), B=(0,2). Two updates per history batch, reset weights to zero at entry, carry both moments and count. Take the first return step on A. Only the first task differs across A,B and C,B. Control and return tasks are constructed feature vectors, without semantic labels.

**Calculation.** In the first coordinate two gradients of sign + or - produce uncorrected first moment +/- (1-beta1^2). Two intervening zero gradients multiply this by beta1^2. The common return gradient +1 gives (1-beta1) +/- beta1^3(1-beta1^2). Squared gradient histories are identical for both coordinates, so the entire second-moment vector, bias corrections and count agree, and the second coordinate of the first moment agrees too. At return both students start at zero, so q=2 theta_1 changes with the opposite sign of the first moment. For k intervening zero gradients, the opposing history overrides the common gradient iff beta1^(k+1)(1+beta1)>1. Reversal ends between k=5 and k=6 for beta1=.9. With two updates per intervening batch, reversal occurs through two full B batches, and ends with three. This threshold concerns the sign; history can still affect magnitude later.

**Controls and information budget.** Two first moments, two second moments, and one shared logical update count (equivalent per-tensor counts) per carried arm. Identical two restored weights and frozen reference, no replay, cache, labels or task identity used to choose a step. Predictions before return adaptation are zero for all four controls. Return outputs after A,B, C,B, zero moments at incoming count four, and fresh Adam are -0.000150407249, +0.000024284865, -0.000109097848, and -0.000199999998, respectively. Clearing moments but preserving the counter is an artificial diagnostic. Fresh Adam also resets the counter. Computation with 50-digit decimal arithmetic checked the loss sign, gradient formula through the constructed graph, moments and reversal thresholds in under ten CPU seconds. Actual gradient computation in the script uses the analytic x/2. The recorded timer rounded to zero. Neither the previous trained checkpoint nor held-out targets were used.

**Scope and decision.** The stored first moment can encode a short history when the student is restored. A,B and fresh move the scalar A prediction in the same direction. A positive scalar learning-rate rescaling of the fresh first step can duplicate the A,B output on this single input. Thus a putative advantage on this fixture could be explained by step size. The histories do not establish task retrieval, improved predictive risk, retention before return, or novelty. A different labeling of these same inputs can change their accuracy ordering.
