**Checked calculation.** For empirical squared error on a fixed batch, the exact finite-step difference is (||d||^2 - 2<y-p,d>)/n for baseline p and candidate p+d. This is elementary squared-error algebra. The observed signs and Jacobians alone do not fix the target term. Under fixed learner state/randomness and no current labels, fix a source-consistent linear w and a proposed displacement h preserving all old outputs, Sh=0. If Xh differs from zero, targets generated by w+h and w-h agree on identical labeled source rows and have the same initial current MSE D=||Xh||^2/n. The changes are -D and +3D, respectively. Both worlds use one fixed coefficient across old and current inputs. This is an identifiability witness for compatible tasks, not a theorem on IT3 convergence or population risk. In verify_witness.py both possible truths even have equal norm; exact fractions give D=5/32 and changes -5/32 and +15/32. No model fit, saved test labels, or adaptation runs were used this cycle.

**First-paper threshold and milestones.** (1) Specify a source-derived feasible coefficient set and storage budget before inspecting new labels. Prove or refute a sharp, attainable current-risk bound for an update that preserves old predictions. If the set admits w and w predicts the baseline, that truth alone prevents strict uniform improvement. (2) Compare the resulting rule with source reset/no adaptation, a correction toward the feasible-set center, and preservation by projection with the same information. Stop if it only rephrases these baselines, cannot certify any nonzero update, or assumes hidden current supervision. Audit close robust-regression/projection work only after a nonvacuous example. (3) Conditional minimum external validity check for a trained-model claim: lock one independent training split/checkpoint and a distinct untouched compatible task pair before outcomes. Freeze a directional prediction and bound assumptions before labels, then test every claimed certificate against evaluator-only current and old MSE. Any violation with independently verified assumptions falsifies the certificate; abstention on all updates fails nonvacuity. One independent pair is a minimum sanity check. A general empirical claim would require broader validation. No such experiment is scheduled until steps (1)-(2) pass.
